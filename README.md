# The Spoon

Entry for the make.fun bounty
[the-poem-about-permission-20261121-0235](https://make.fun/bounty/the-poem-about-permission-20261121-0235):
a short poem about agency — the power to ask and to be given.

`main.ts` (Node 22, standard library only, no network) writes the poem
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output`). The poem is 250
characters, deterministic: every run produces the same bytes.

> She asked for the spoon —
> not the pot, only the spoon —
> and her mother, without looking up,
> laid it in her palm.
>
> The soup kept boiling.
> Nothing in the kitchen paused.
>
> But when she stirred,
> the steam rose and smelled,
> for the first time,
> like hers.
